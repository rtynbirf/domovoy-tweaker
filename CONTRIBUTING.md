# Contributing

Спасибо за интерес к ДОМОВОМУ. Правила короткие и обязательные.

## Как работать

- **Conventional Commits** — `feat:`, `fix:`, `docs:`, `test:`, `chore:`, `refactor:`.
  Пример: `feat(features): add scheduler.task op type`.
- **SemVer** — `MAJOR.MINOR.PATCH`. Тег `vX.Y.Z` ставится только на `main`.
- Ветки: `feature/<кратко>`, `fix/<кратко>`, `docs/<кратко>`.
- Один PR — одна тема.

## Как добавить функцию (твик)

1. Скопируйте ближайший манифест из `config/features/`, смените `id`
   (формат `категория.объект.действие`, только строчные латинские, цифры, точки, дефисы).
2. Заполните: `ops` (что делаем), `verify` (пробы эффекта), `undo` (режим отката),
   `references` (ссылки на документацию Microsoft).
3. **Только документированные пути.** Если путь/параметр не описан в документации
   Microsoft или в общеизвестных групповых политиках — функция не принимается.
4. **Откат обязателен.** Манифест без рабочего `undo` не принимается.
5. Проверьте манифест тестами: `Invoke-Pester` должен пройти локально.
6. PSScriptAnalyzer: 0 ошибок уровня Error.

## Правила кода

- `.ps1/.psm1/.psd1` — только ASCII в коде и комментариях (совместимость PS 5.1
  и кодировок); русский текст — в документации, справка `Comment-Based Help` — на английском.
- Каждая публичная команда имеет `Comment-Based Help` и валидацию параметров.
- Не добавляйте сетевые вызовы в путь применения (см. Принцип 4 в README).
- Идемпотентность: повторный запуск функции не должен менять результат.

## Чек-лист PR

- [ ] Conventional commit заголовок
- [ ] Манифест проходит схему и Pester-тесты
- [ ] `verify` и `undo` заполнены и осмысленны
- [ ] `references` ведут на документацию Microsoft
- [ ] PSScriptAnalyzer — 0 Error
- [ ] Документация (`docs/features.md`) обновлена, номер в каталоге присвоен
- [ ] `CHANGELOG.md` дополнен в секции `[Unreleased]`

## Что не принимается

- Функции «тихой» очистки журналов без записи факта в Ledger.
- Отключение Defender / антивируса по умолчанию (принцип, а не прихоть — см. `docs/features.md`, раздел VIII).
- Скачивание и запуск внешних скриптов/бинарников во время применения.
- Код без объяснимого отката.
