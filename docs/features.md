# Полный нумерованный каталог функций ДОМОВОЙ

Легенда статуса: `✅ vX.Y` — реализовано в вехе · `vX.Y` — запланировано ·
`отказ` — сознательно не делаем (и почему).

Колонка «истоки» показывает, какой механизм из Modern Tweaker 2.0/3.0
(реверс-инжиниринг — `analysis/modern-tweaker-case-study.md`) эта функция
переосмысляет. Имена в кавычках — восстановленные символы из бинарников.

Номера — постоянные идентификаторы фич: присвоены один раз и никогда не меняются,
новые записи получают следующий свободный номер и попадают в свой раздел
(поэтому внутри раздела номера идут с пропуском — это осознанно).
