# Графический интерфейс (v0.7.0)

`Show-Domovoy` — тонкий WinForms-клиент поверх CLI. Это тот же модуль, без
дублирующей логики: каждое действие GUI — ровно одна команда CLI, которую вы
могли бы набрать руками. GUI только собирает ввод (выбранная фича, нажатая
кнопка) и показывает результат.

## Запуск

```powershell
Import-Module Domovoy
Show-Domovoy
```

WinForms есть в комплекте Windows и PowerShell 5.1/7 — ничего ставить не надо.
На не-Windows команда честно падает с сообщением, что нужен Windows.

## Что на экране

- **Список фич** (слева, на весь остаток окна): Id, название, риск и статус из
  журнала (`applied` / `undone`). Источник — `Get-DomovoyFeature`, то же
  самое, что видит CLI.
- **Панель фичи** (внизу): `Dry-run` (план без изменений), `Apply...`
  (с подтверждением; снимок до операции, пробы после, запись в журнал),
  `Undo...` (с подтверждением), `Effect` (честная матрица проб).
- **Тулбар** (сверху): `Drift scan`, `Change report`, `Network report`,
  `Auto-heal (dry-run)`, `Switch theme`, `Export policies`, `Refresh`.
- **Журнал сессии** (внизу, моноширинный): перед каждым действием печатается
  строка `CLI: ...` — а затем исполняется ровно эта команда.

## Правило тонкого клиента

Критерий вехи: «каждое действие GUI выполнимо той же командой CLI». В GUI это
не договорённость, а механика: кнопка строит строку команды, печатает её в
журнал сессии и исполняет **ту же самую строку**, скомпилированную в
скриптблок. Снимки, dry-run, проверка elevation, пробы и события журнала
происходят внутри обычных публичных команд — снимки/undo/авто-лечение
работают с GUI-действиями так же, как с командами, набранными руками.

## Ограничения (честные)

- Apply/Undo/тема требуют elevation — общий конвейер проверяет его для любого
  apply (инвариант I5), даже когда значения живут в HKCU. Запускайте
  PowerShell от администратора.
- Кнопка авто-лечення запускает `Invoke-DomovoyAutoHeal` **без** `-Apply`
  (dry-run). Лечение по расписанию включается только явной opt-in командой
  `Register-DomovoyWatchdog` — GUI этот шаг сознательно не упрощает.
- Экспорт политик из GUI создаёт папку экспорта в хранилище; для точечных
  путей (`-OutputDir`) используйте CLI.
- WinForms — только Windows; CI гоняет только сборку окна (`-Preview`),
  живой цикл окон остаётся на вашей машине.
