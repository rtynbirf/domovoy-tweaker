# Твик = декларативный манифест с гарантированным откатом (П39)

*Волна ×4 · 2026-11-11 · repo `domovoy-tweaker` · issue #20*

## Формула

**Каждый твик описывается декларативным манифестом (ключ → старое значение →
новое значение). `DOMOVOY-ONECLICK.bat` и человек — лишь зовут исполнителя.
Откат = обратный проход undo-журнала. Домовой помнит, как всё было.**

## Исполнитель

```powershell
# проверить форму манифеста (ноль мутаций)
tools/Invoke-DomovoyTweakJournal.ps1 -Check -Manifest config/features/030-theme-dark.json

# применить твик (старые значения УПРЕЖДАЮЩЕ ложатся в undo-журнал)
tools/Invoke-DomovoyTweakJournal.ps1 -Manifest config/features/030-theme-dark.json

# что было бы откачено (сухой прогон — инвариант I3)
tools/Invoke-DomovoyTweakJournal.ps1 -Undo

# откатить последнюю партию твика (обратный проход журнала, LIFO)
tools/Invoke-DomovoyTweakJournal.ps1 -Undo -Apply
```

Журнал: `%LOCALAPPDATA%\Domovoy\tweaks\journal.jsonl` (переопределяется
`-JournalPath`) — JSONL, append-only: `op.begin` (старое значение записано
ДО мутации) → `op.applied` → `batch.done`; откат добавляет `batch.undone`.

## Гарантии

1. **Write-ahead**: старое состояние (значение + тип + «был ли ключ» /
   тип запуска службы) в журнале до первого байта мутации. Обрыв применения
   посреди пути лечится откатом: журнал уже держит прошлое.
2. **LIFO-обратный проход**: значения восстанавливаются с точными типами
   (DWord/QWord/String/ExpandString/Binary/MultiString); значения, которых
   не было, удаляются; ключ, созданный твиком, снимается вместе с пустыми
   предками.
3. **Обязательность отката**: повторное применение твика без отката
   предыдущего — отказ (`партия … — откат обязателен`).
4. **Дрейф-страж**: если манифест заявляет `old`, а мир уже другой —
   применение запрещено (домовой не лжёт).
5. **Fail-closed whitelist**: операции вне `registry.set` / `service.startup`
   (appx.remove, scheduler.task, network.*) — отказ ДО любой мутации;
   расширение whitelist — осознанный атом, а не «как получится».

## Приёмка (машинная, issue #20)

- `tests/Domovoy.V15.TweakJournal.Tests.ps1`:
  - **все 58 манифестов** `config/features/*.json`: apply → undo →
    канонический дамп склада байт-в-байт равен исходному (память-склад,
    работает на любой ОС);
  - **живой реестр** (windows-latest): черновой ключ HKCU с шестью типами
    значений + создаваемый твиком подключ; равенство доказано SHA256
    `reg.exe export` до/после — байт-в-байт буквально;
  - обрыв посреди применения → откат чинит до байта; повтор без отката
    запрещён; undo без `-Apply` ничего не меняет; дрейф-страж;
  - PSScriptAnalyzer по настройкам репо: 0 ошибок и 0 предупреждений
    на исполнителе.

## Связь с существующим ядром

Модуль `src/Domovoy` (v1.6) ведёт change-ledger со snapshot-undo
(`Invoke-DomovoyFeature`/`Undo-DomovoyFeature`) — П39 добавляет
декларативную запись «ключ → старое → новое» и независимого исполнителя
с write-ahead журналом; ядро не переписывалось (append-only волны).
`DOMOVOY-ONECLICK.bat` остаётся обёрткой локального CI — зовёт исполнителя,
ничего не импровизирует.
