## v2.0 (дверь закрыта до конца v1.x — по MAJOR-политике spec §10)

Сюда попадает только то, что требует ломать замороженные форматы:
подъём `schemaVersion` журнала, смена семантики op-типов, переезд хранилища.
Пока таких причин нет — веха пуста намеренно. Правило: веха открывается
конкретным списком ломающих причин, а не желанием «сделать красиво».

## Beyond (идеи из roadmap.md + что принесла ревизия; не обещания)

- **Мульти-машина** (roadmap): журнал и профили как вход для Intune/SCCM-конвейеров — экспорт уже есть (v0.7), не хватает импорта-на-целевой-машине с журналом-приёмником.
- **«Семейный домовой»** (roadmap): несколько профилей на одной машине с раздельными журналами (сегодня журнал один на хост).
- **Мастер переноса** (roadmap): журнал как источник переноса состояния на новую Windows — dry-run-отчёт «что перенесётся, что не может».
- **TUI-режим** для консольных сессий (класс 2026: sparkle/Wintoys дали красивые приложения; наш ответ — не тяжелее WinForms, а PSReadLine-меню поверх тех же CLI-команд).
- **Экспорт/импорт профиля одним файлом** (профиль + применённые фичи + верификация) — для арбитража «что настроено на этой машине».
- **Монитор дрейфа в GUI** (v0.7 GUI показывает статусы, но не живой скан по кнопке в тулбаре — расширение тонкого клиента).
