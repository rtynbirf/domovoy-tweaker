## 3. Что изменилось в продукте (сводка)

- `packaging/shim/DomovoyPortable.cs` — скрытие консоли + отсоединённый
  GUI-старт + `--wait` + версионный selftest-гейт.
- `packaging/shim/AssemblyInfo.cs` (новый) + `src/Domovoy/domovoy.ico`
  (новый) — идентичность продукта; на CI собирается `csc /win32icon` +
  атрибуты, в песочнице — сгенерированный Win32 `.res` (та же иконка и
  VERSIONINFO байт-в-байт по смыслу).
- `src/Domovoy/Public/Show-Domovoy.ps1` — асинхронный воркер, статус-бар,
  поиск, перехват ошибок, иконка/DPI/стили; дисциплина замыканий
  зафиксирована (все поздние ссылки — через `$state`).
- `packaging/shim/domovoy.ps1` — фатальный guard GUI-режима (диалог + лог).
- Тесты: асинхронный жизненный цикл и фильтр (`Domovoy.V07.Tests.ps1`),
  контракт идентичности (`Domovoy.Portable.Tests.ps1`).

## 4. Честные остатки (не спрятаны)

1. **Подпись кода** — техническая работа в репо готова (CI-джоб), нужен
   сертификат владельца; до тех пор SmartScreen предупреждает, это
   ожидаемо для открытого кода (источник 1: «unsigned files … starting
   from zero reputation»).
2. **Автообновление внутри GUI** — не сделано в v1.6.0, кандидат в v1.7
   (проверка релизов GitHub API, без автоскачивания).
3. **Переключение языка без переоткрытия окна** — метки строятся при
   открытии; сообщение пользователю честно просит переоткрыть окно.
